# Scrolls Changelog

## [0.1.0] - 2026-09-28

- Search and browse notes in a configurable notes directory, sorted by most recently opened
- Inline preview with created, modified, last opened, and size metadata
- Create notes by typing a name and hitting Enter
- Open in TextEdit or any app, reveal in Finder, copy the path
- Delete notes and folders to Trash with confirmation
- Notes Directory preference (default: `~/Documents/notes`)
